= Tables

AsciiDoc tables are converted to Confluence tables. The following table features are supported:

== Simple Table

A table without header row.

[listing]
....
[cols="2"]
|===
| A1
| A2

| B1
| B2
|===
....

[cols="2"]
|===
| A1
| A2

| B1
| B2
|===


== Table with Header

A table with first row as header.

[WARNING]
====
Currently, only column headers, are supported, but row headers not.
====

[listing]
....
[cols="2", options="header"]
|===
| Column 1
| Column 2

| A1
| A2

| B1
| B2
|===

....

[cols="2", options="header"]
|===
| Column 1
| Column 2

| A1
| A2

| B1
| B2
|===

== Table with AsciiDoc Cell

Table cells may also contain structured content, e.g. bullet lists:

[listing]
....
[cols="2", options="header"]
|===
| Column 1
| Column 2

|A1
a|
* A2
* A3
* A4
|===
....

[cols="2", options="header"]
|===
| Column 1
| Column 2

|A1
a|
* A2
* A3
* A4
|===

== Table with Column Widths

The relative width of the columns of a table can be configured using the `cols` attribute, either as proportional
values (e.g. `cols="1,3"`) or as percentage values (e.g. `cols="25%,75%"`). In both cases, the column widths are
published as percentage values relative to the width of the table.

[NOTE]
====
Column widths are only published if at least one column width is defined explicitly. If the `cols` attribute only
defines the number of columns (e.g. `cols="2"` or `cols="2*"`), or if the `%autowidth` option is set on the table, the
columns are sized by Confluence based on their content. Individual columns can be sized based on their content using
`~` as column width (e.g. `cols="25%,~"`).
====

[NOTE]
====
Column widths are honoured by Confluence Server / Data Center. The new Confluence Cloud editor might apply its own
column sizing logic instead.
====

[listing]
....
[cols="1,3", options="header"]
|===
| Column 1
| Column 2

| A1
| A2

| B1
| B2
|===
....

[cols="1,3", options="header"]
|===
| Column 1
| Column 2

| A1
| A2

| B1
| B2
|===

Column widths can be combined with the `width` attribute of the table:

[listing]
....
[cols="20%,30%,50%", width="100%", options="header"]
|===
| Column 1
| Column 2
| Column 3

| A1
| A2
| A3
|===
....

[cols="20%,30%,50%", width="100%", options="header"]
|===
| Column 1
| Column 2
| Column 3

| A1
| A2
| A3
|===

== Table with Width

Tables can be configured with a specific width using the `width` attribute. This allows to control the horizontal space the table occupies.


[NOTE]
====
Table width values are not honoured explicitly by the new Confluence editor.
Table width values are mapped to the default, wide or full-width table layout based on internal Confluence editor logic.
====

=== Percentage Width

[listing]
....
[cols="2", width="100%", options="header"]
|===
| Column 1
| Column 2

| A1
| A2

| B1
| B2
|===
....

[cols="2", width="100%", options="header"]
|===
| Column 1
| Column 2

| A1
| A2

| B1
| B2
|===

=== Fixed Width

[listing]
....
[cols="2", width="400px", options="header"]
|===
| Column 1
| Column 2

| A1
| A2

| B1
| B2
|===
....

[cols="2", width="400px", options="header"]
|===
| Column 1
| Column 2

| A1
| A2

| B1
| B2
|===
